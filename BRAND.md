# Brand assets

The MIT license in this repo covers the code and the text of the skills.

It does not cover the Bluefyn brand. The Bluefyn name, the logo, the brand book and the graphics drawn in
the Bluefyn style identify Bluefyn. They are in this repo so that work made for Bluefyn looks right.

You are welcome to:

- read how the skills are built and reuse the code and the approach for your own brand
- fork the repo and replace the brand rules, logo, colors and font with your own

Please do not:

- use the Bluefyn name or logo on your own product, site or documents
- publish material that looks like it comes from Bluefyn

Third-party parts keep their own licenses. See `THIRD-PARTY.md`.
